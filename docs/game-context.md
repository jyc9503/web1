# 카오스 제로 나이트메어(카제나) 게임 맥락

모든 기획의 공통 배경이다. 새 기획을 시작할 때 먼저 읽고, 각 기획의 `decisions.md` "게임 맥락"에 필요한 부분만 옮긴다.

## 상태 안내

- 아래 내용은 **웹 검색 결과 요약**에서 가져왔다. 원문 페이지는 열람하지 못했다(세션 네트워크 제한).
- 따라서 전부 `검증필요`다. 사용자가 확인하거나 정정한 항목만 `확정`으로 바꾼다.
- 검색 요약끼리 서로 다른 내용이 있으면 아래 "불일치"에 적었다.
- 사용자가 직접 알려주는 설정이 항상 이 문서보다 우선한다.

## 세계관·톤 `검증필요`

- '카오스'라는 미지의 존재에 오염되어 멸망한 우주를 배경으로 한다.
- 폐허가 된 우주선 위에서 트라우마를 가진 요원 일행을 이끄는 이야기라는 서술이 있다.
- 다크 판타지, SF, 코즈믹 호러 등 출처마다 표현이 다르다.

## 핵심 시스템·용어 `검증필요`

| 용어 | 검색 요약 기준 설명 | 비고 |
|---|---|---|
| 카오스 | 핵심 콘텐츠. 이벤트와 전투로 가득한 행성을 탐험하는 로그라이크 모드 | 실패해도 일정 수준의 성장·보상을 얻고 반복 도전하는 구조 |
| 번뜩임 | 카드의 효과나 작동 방식을 변경하는 시스템 | 라이브 서비스의 핵심 매력으로 평가된다는 서술 |
| 붕괴 시스템 | 캐릭터의 트라우마를 게임 플레이와 연결 (김형석 PD 설명) | 구체적 규칙은 확인 못 함 |
| 제로 시스템 | 엔드 콘텐츠. 계정 레벨 40 이후 도전 | 구체적 규칙은 확인 못 함 |
| 파티 / 덱 | 전투는 3인 파티로 진행하고, 각 캐릭터가 카드를 하나의 공유 덱에 더한다 | 영문 출처 기준 |
| 정신력(Sanity) | 체력과 별개로 관리하는 자원 | 한국어 공식 명칭은 확인 못 함 |
| 캐릭터 분류 | 영문 출처에서 캐릭터를 class로 분류, 예로 Controller(지원) 계열이 있다 | 한국어 명칭과 전체 분류는 확인 못 함 |
| 출격(Sortie) | 2026-04 하프 애니버서리 업데이트로 추가된 덱빌딩 로그라이크 모드라는 서술 | 한국어 명칭·규칙 확인 못 함 |

## 불일치·불확실한 점

- 세계관 장르 표현이 출처마다 다르다(다크 판타지 / SF / 코즈믹 호러).
- 캐릭터 수(영문 가이드 기준 38명, 5성 26 / 4성 12)는 제3자 사이트 수치라 최신이 아닐 수 있다.
- 한국어 공식 용어를 확인하지 못한 항목이 많다. 기획 문서에는 사용자가 쓰는 표기를 따른다.
- 카드 코스트, 턴 규칙, 속성·상성, 재화 체계는 확인하지 못했다.

## 사용자에게 확인할 것 (첫 기획 인터뷰에서 함께 물을 것)

- 위 용어 중 틀린 것
- 기획 대상이 되는 부분이 위 시스템 중 어디에 붙는지(카오스 모드, 번뜩임, 붕괴 등)
- 기획서에서 반드시 써야 하는 공식 용어 표기
