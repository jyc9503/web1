## 상태 안내

- 아래 내용은 **웹 검색 결과 요약**에서 가져왔다. 기사 원문은 열람하지 못했다(세션 네트워크 제한).

## 불일치·불확실한 점

- 세계관 장르 표현이 출처마다 다르다(다크 판타지 / SF / 코즈믹 호러).
- 출격(Sortie)이 처음 추가된 시점이 출처마다 다르다. 이전 조사에서는 2026-04 추가라는 서술이 있었으나 이번 조사에서는 확인하지 못했다.
- 시즌 번호별 정확한 날짜(시즌 2, 3)는 확인하지 못했다.
- 2인 협력전의 규칙과 위치는 기사 제목에서만 확인했다.
- 카드 코스트, 턴 규칙, 속성·상성, 재화 체계는 확인하지 못했다.
- 캐릭터 수(영문 가이드 기준 38명)는 제3자 수치이고 이후 계속 늘었을 것이다.
