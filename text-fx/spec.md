# 텍스트 연출 효과 기획서

작성 2026-11-07 · 수정 2026-11-14 · 전영철

## 1. 개요

슬픈 원령 등의 대사에 쓸 텍스트 연출 3종을 정의한다. 기존 `<$이름>…</$이름>` 태그 규칙에 프리셋 이름을 더해 적용하고, 기획자는 프리셋 이름만 고른다.

| 효과 | 프리셋 | 동작 | 사용 장면 |
| --- | --- | --- | --- |
| 텍스트 드롭 | `$drop_s` `$drop_m` `$drop_l` | 글자의 분신이 원본에서 분리되어 아래로 떨어진다 | 슬픈 원령의 대사 |
| 텍스트 상승 | `$rise_s` `$rise_m` `$rise_l` | 드롭의 반대. 분신이 원본에서 분리되어 위로 떠오른다 | 승천이나 해방의 순간 |
| 텍스트 그라데이션 | `$grad_op` `$grad_tl` `$grad_yr` | 태그로 감싼 구간의 글자 색이 실시간으로 변한다 | 문장 속 강조, 감정의 고조 |

- 공통 원칙: 원본 글자는 사라지거나 다른 글자로 바뀌지 않는다. 드롭·상승은 원본 위에 분신을 얹고, 원본은 잠깐 밀렸다가 제자리로 돌아온다. 그라데이션은 색만 바꾼다.
- 움직이는 시안: 같은 폴더의 `index.html` (사용법은 부록 참고)

## 2. 사용법 (기획자용)

### 태그 형식

```
<$프리셋이름>대상 글자</$프리셋이름>
```

- 여는 태그와 닫는 태그에 같은 프리셋 이름을 쓴다. 기존 `<$wave_s>흔들리는 효과</$wave_s>` 와 같은 방식이다.
- 프리셋 이름은 `효과_규격` 이다. 효과는 `drop`, `rise`, `grad` 이고, 규격은 세기를 뜻하는 `s`(작게), `m`(보통), `l`(크게) 이다. 그라데이션은 규격 대신 색 약자(시작색·끝색 첫 글자)를 쓴다.
- 세부 값(속도, 거리, 세기 등)은 태그에 쓰지 않는다. 값은 프리셋 정의표에만 있고, 다른 값이 필요하면 플머에게 새 프리셋을 요청한다.

### 프리셋 목록

| 프리셋 | 효과 | 느낌 |
| --- | --- | --- |
| `$drop_s` | 텍스트 드롭 | 은은하게. 분신이 적고 짧게 떨어진다 |
| `$drop_m` | 텍스트 드롭 | 보통 세기 |
| `$drop_l` | 텍스트 드롭 | 강하게. 분신이 많고 멀리 떨어지며, 닿은 글자가 크게 흔들린다 |
| `$rise_s` | 텍스트 상승 | 은은하게. 분신이 적고 낮게 떠오른다 |
| `$rise_m` | 텍스트 상승 | 보통 세기 |
| `$rise_l` | 텍스트 상승 | 강하게. 분신이 많고 높이 떠오르며 크게 흔들린다 |
| `$grad_op` | 텍스트 그라데이션 | 주황, 분홍, 보라 |
| `$grad_tl` | 텍스트 그라데이션 | 청록, 연한 파랑, 연보라 |
| `$grad_yr` | 텍스트 그라데이션 | 노랑, 주황, 빨강 |

### 사용 예시

```
<$drop_m>나는 아직 여기 있어요</$drop_m>
나는 <$drop_s>아직</$drop_s> 여기 있어요
<$rise_m>이제야 가벼워졌구나</$rise_m>
그날의 하늘은 <$grad_op>유난히 붉었다</$grad_op>
<$drop_m><$grad_tl>아직 떠나지 못했어요</$grad_tl></$drop_m>
```

### 사용 가이드

- 처음에는 `m` 을 쓰고, 분위기에 따라 `s`(조용한 장면)나 `l`(감정이 터지는 장면)로 바꾼다.
- 드롭·상승의 접촉 반응(분신이 지나가며 다른 글자를 건드림)은 대사가 두 줄 이상일 때 잘 보인다. 한 줄 대사에서는 분리되는 순간 양옆 글자가 딸려가는 정도만 보인다.
- 한 대사에 구간을 여러 개 둘 수 있고, 구간마다 다른 프리셋을 쓸 수 있다. 드롭·상승은 구간마다 분신이 생기므로 구간이 많을수록 분신도 많아진다. 대사 하나의 분신 수에는 상한이 있다(구현 참고).
- 태그 안에 줄바꿈이나 공백이 있어도 된다.

### 적용 범위와 조합

- 연출은 태그 안의 글자에만 적용된다. 단, 드롭·상승의 접촉 반응은 같은 텍스트 id(Yuna text 단위) 안이면 태그 밖 글자도 받는다. 다른 텍스트의 글자는 건드리지 않는다.
- 쓸 수 있는 곳: 기존 태그를 쓸 수 있는 텍스트라면 어디든 쓸 수 있다. 범위는 기존 태그 처리를 따른다.
- 그라데이션은 기존 색상 변경 태그와 같은 취급이다. 드롭·상승 안에 넣을 수 있다. 같은 글자에 그라데이션과 색상 태그가 함께 걸리면 기존 색상 태그 규칙을 따른다.
- 글자를 움직이는 효과(드롭, 상승, 기존 `wave` 등)끼리는 겹쳐 쓸 수 없다.

### 규칙과 오류 처리

| 상황 | 처리 |
| --- | --- |
| 움직이는 효과끼리 겹침 | 안쪽 태그만 적용하고 경고한다 |
| 빈 태그 | 무시한다 |
| 없는 프리셋 이름 | 기존 태그 처리 방식을 따른다(확인 필요). 연출 없이 글자만 표시하는 것을 제안한다 |
| 열린 태그를 닫지 않음 | 기존 처리 방식을 따른다(확인 필요). 문장 끝에서 자동으로 닫고 경고 로그를 남기는 것을 제안한다 |

### 시작과 종료

- 효과가 걸린 대사는 타자 연출 없이 페이드인으로 나타나고, 나타나는 즉시 연출을 시작한다. 시작 지연이나 지속 시간 값은 없다.
- 대사가 화면에 있는 동안 연출을 계속 반복한다. 분신은 무작위로 생겨서 같은 대사도 매번 다르게 보인다.
- 대사가 페이드인·아웃 중이라 반투명하면, 분신과 잔상의 투명도에도 대사의 투명도를 곱한다.
- 대사가 닫히면 새 분신을 만들지 않고, 움직이던 분신은 대사와 함께 페이드아웃한다.
- 스킵·빨리감기 중에도 평소와 같이 동작한다.
- 말풍선 대사는 스토리 로그(백로그)에 남지 않으므로 백로그 처리는 필요 없다.
- 효과를 끄는 설정(모션 감소 등)은 두지 않는다.

## 3. 효과별 연출

### 3-1. 텍스트 드롭

원본 글자는 그대로 남고 그 복제(분신)만 흘러내려, 글자가 스스로의 일부를 떨어뜨리는 것처럼 보이게 한다.

1. 태그 안 글자 하나를 골라 분신을 만든다. 분신은 원본과 겹친 채 투명하게 시작해, 윗면을 고정한 채 아래로 늘어난다(늘어남).
2. 늘어나는 동안 원본 글자가 아래로 살짝 내려앉는다(내려앉음). 분신은 내려앉은 위치에 붙어 있다.
3. 분리 시간이 끝나면 분신이 떨어져 나가 낙하하고, 원본은 스프링처럼 제자리로 돌아온다(복귀 탄성). 분리되는 순간 같은 줄 양옆 글자가 약하게 딸려간다.
4. 낙하 중 분신이 다른 글자와 겹치면 그 글자가 낙하 방향으로 밀려났다가 돌아오고 잠깐 밝아진다(접촉 반응). 분신 하나당 글자마다 한 번만 반응한다.
5. 빠를수록 분신이 세로로 길어지고, 좌우로 기울며 벌어진다. 뒤에 흐린 잔상이 남는다.
6. 낙하 거리의 20% 지점부터 서서히 투명해지며 사라진다. 잔상도 같은 기준으로 사라져서 끝에서 갑자기 끊기지 않는다.

드롭·상승 공통:

- 분신은 대사 영역(말풍선) 밖으로 나가도 잘라내지 않고 그린다.
- 분신 색은 원본 글자 색에서 자동으로 계산한다(조금 더 진하고 선명하게). 그라데이션이 걸린 글자는 분신이 생기는 순간의 색에서 계산한다.

### 3-2. 텍스트 상승

드롭을 위아래로 뒤집은 연출이다. 분신이 원본에서 분리되어 위로 떠오른다(역재생이 아니다). 동작 순서는 드롭과 같고 아래 항목만 다르다.

| 항목 | 드롭 | 상승 |
| --- | --- | --- |
| 분신이 늘어나는 방향 | 윗면 고정, 아래로 | 아랫면 고정, 위로 |
| 원본의 반응 | 아래로 내려앉음 | 위로 살짝 들림 |
| 이동 | 중력으로 아래로 가속 | 부력으로 위로 가속. 속도 상한이 낮아 천천히 떠오른다 |
| 좌우 움직임 | 낙하하며 약간 기울어짐 | 올라가며 좌우로 흔들림 |
| 접촉 반응 | 아래쪽 줄 글자가 아래로 밀림 | 위쪽 줄 글자가 위로 밀림 |
| 사라지기 시작하는 지점 | 이동 거리의 20% | 이동 거리의 60% |

### 3-3. 텍스트 그라데이션

태그로 감싼 구간의 글자 색이 팔레트를 따라 실시간으로 변한다. 모양과 위치는 바뀌지 않고, 구간 밖 글자는 원래 색(대사 텍스트의 기본 글자색)을 유지한다.

- 팔레트는 색 끝점 3개를 부드럽게 이어 한 바퀴 돌아 처음으로 돌아오는 순환 구조다.
- 구간 양 끝 글자는 원래 색과 섞어 경계를 부드럽게 한다.
- 변화 방식은 두 가지이고, 현재 프리셋은 모두 `flow` 다.

| 변화 방식 | 동작 |
| --- | --- |
| `flow` | 구간 안에서 팔레트가 글자를 따라 한쪽으로 흐른다. 구간 전체가 팔레트 한 바퀴를 포함한다 |
| `sync` | 구간 전체가 같은 색으로 함께 변한다 |

| 프리셋 | 약자 | 색 끝점 |
| --- | --- | --- |
| `$grad_op` | orange·purple | `#ffb347` → `#ff5e7e` → `#8e5bff` |
| `$grad_tl` | teal·lavender | `#7ef0e0` → `#9db8ff` → `#e5d4ff` |
| `$grad_yr` | yellow·red | `#fff3a0` → `#ff9a3c` → `#e0342b` |

새 팔레트를 만들 때는 약자가 기존 것과 겹치지 않게 한다.

## 4. 프리셋 정의표

- 프리셋 이름 하나가 아래 값 묶음 하나를 가리킨다. 대사 텍스트에는 이름만 쓴다.
- 값의 수정과 새 프리셋 추가는 플머가 한다. 저장 위치와 형식은 구현에서 관리하고, 값을 바꿀 때 코드나 대사 텍스트를 고치지 않아야 한다.
- 값 이름은 시안의 변수명과 같다.
- px 값은 글자 크기 40px 기준이다. 실제로는 글자 크기에 비례해서 쓴다(글자 크기 ÷ 40을 곱한다). '글자 크기 비례' 열은 `m` 값을 em으로 적은 것이다.

## 5. 구현 참고 (플머용)

시안(웹 Canvas 2D)이 실제로 쓴 규칙과 값이다. 엔진과 무관하게 적었고, 실기기 성능은 측정하지 않았다. px 값은 글자 크기 40px 기준이다.

### 태그 처리와 프리셋 조회

- 파서는 태그 이름 전체(예: `drop_m`)를 키로 프리셋 정의표를 조회한다. `_` 로 쪼개지 않고 표의 키와 그대로 맞추는 것을 권장한다.
- 닫는 태그는 이름이 같은 가장 가까운 열린 태그와 짝짓는다. 중첩된 태그를 스택으로 처리하면 된다.
- 표에 빠진 값은 `m` 의 값을 쓰는 것을 제안한다.

### 1. 조각 분할

- 문구 전체를 글자 단위 조각으로 나누고, 조각마다 중심 위치(cx, cy)와 폭(w)을 구한다. 공백은 조각이 아니다.
- 글자 하나는 사용자가 한 글자로 보는 단위다(이모지, 결합 문자 포함). 다국어와 특수문자를 모두 쓰고, 오른쪽에서 왼쪽으로 쓰는 언어는 지원하지 않는다.
- 구간 안 조각만 분신을 만든다. 구간 밖 조각도 같은 방식으로 그리고, 지나가는 분신에 닿으면 접촉 반응을 받는다.
- 분신은 자기 구간의 프리셋 값을 쓴다. `rate` 는 구간마다 따로 적용한다.
- 원본도 조각 단위로 그리고, 조각마다 위치 오프셋을 줄 수 있어야 한다. 조각 위치는 한 줄 전체를 기준으로 재서 글자 간격이 어긋나지 않게 한다. 자동 줄바꿈 후의 화면상 줄을 기준으로 하고, 대사 텍스트의 줄바꿈 문자도 줄바꿈으로 센다.

### 2. 분신의 수명

1. 생성: 매 프레임 `rate × dt` 확률로 분신 하나를 만든다. 분신이 붙지 않은 조각 중 무작위로 고른다. 위치와 기울기 방향도 무작위이고 시드는 고정하지 않는다. 시안의 상한은 대사(텍스트) 하나당 동시 분신 16개다.
2. 분리 대기(`hang` 초, 분신마다 ±20%): 분신이 원본과 겹친 채 불투명도가 `alpha` 의 20%에서 100%로 올라가고, 세로 배율이 1에서 `stretch` 까지 부드럽게(smoothstep) 커진다. 고정점은 드롭은 윗면, 상승은 아랫면이다. 가로는 약간 줄여 중량감을 준다(1 − 0.06 × (stretch − 1)).
3. 낙하 또는 상승: 속도에 `gravity × dt` 를 방향에 맞춰 더한다. 속도 상한은 드롭 900, 상승 300 px/s다.
4. 소멸: 본체가 `dist` 에 이르고 뒤따르는 잔상도 모두 사라진 뒤에 지운다. 그 조각에는 다시 분신을 만들 수 있다.

이동 중의 표현:

- 세로 길이: 속도비 s(0~1, 기준 속도 드롭 600, 상승 220 px/s)에 따라 +0.3 × s. 분리 때의 `stretch` 는 이동 1.5em 동안 1로 풀린다.
- 기울기: `tilt`° × 분신마다 정해진 부호(±) × min(이동 거리 / 80, 1).
- 좌우: 드롭은 이동 거리 × 0.05만큼 한쪽으로 쏠리고, 상승은 `sway` 폭으로 사인파 흔들림.
- 불투명도: 이동 거리의 `fade` 지점까지 `alpha`, 이후 직선으로 0까지 줄인다. 잔상은 각자 자기 이동 거리로 같은 식을 쓴다. 본체가 끝에 이르러도 잔상이 남아 있으면 분신을 유지한다.
- 잔상: `trail` 개. k번째 잔상은 본체보다 k × (10 + |속도| × 0.035) px 뒤에, 불투명도 본체의 0.5/k 배로 그린다.
- 최종 불투명도에는 대사의 투명도(페이드인·아웃)를 곱한다.

### 3. 원본 조각의 스프링 (내려앉음, 복귀, 접촉)

- 조각마다 위치 오프셋(x, y)과 속도를 스프링으로 관리한다. 평상시 목표는 0이다.
- 분신이 분리 대기 중이면 목표 y를 방향 × `sag` × smoothstep(진행도)로 둔다. 분리되면 목표가 0으로 돌아가 원본이 복귀한다.
- 스프링 상수 k = 160, 감쇠비 ζ = 1 − 0.85 × `bounce`, 감쇠계수 c = 2√k × ζ. `bounce` 0은 반동 없이 돌아오는 임계 감쇠다.
- 분신은 분리된 순간의 원본 오프셋 위치에서 떠난다.

### 4. 접촉 판정

- 이동 중인 분신의 중심이 같은 텍스트 id 안의 다른 조각과 겹치는 순간을 조각마다 한 번만 판정한다(본체가 끝에 이른 뒤에는 판정하지 않는다). 가로 |Δx| < (분신 폭 + 조각 폭) / 2 × 0.8, 세로 |Δy| < 글자 크기 × 0.55 일 때다.
- 겹치면 그 조각의 속도에 `touch` × 20을 진행 방향으로 더한다(분신 속도와 무관하고, 드롭과 상승이 같다). 밝기 플래시(1에서 0으로 약 0.4초)를 걸고, 가로로도 무작위 소량의 흔들림을 준다.
- 같은 줄 양옆 조각에는 한 칸 떨어진 조각에 40%, 두 칸에 18%를 같은 방식으로 더한다.
- 분리되는 순간에는 양옆 조각에 `touch` × 9의 40%, 18%를 더해 딸려가는 느낌을 준다. 밝기 플래시는 60% 세기다.

### 5. 그라데이션 계산

- 구간 글자 수를 n, 글자 순서를 i(0부터)로 두고 u = i / (n − 1)이다. `flow` 는 pos = u − t × `speed`, `sync` 는 pos = t × `speed` 로 팔레트의 위치를 구한다.
- pos는 0~1로 말아 쓰고, 끝점 사이는 smoothstep으로 보간한다(시안은 sRGB 값 직접 보간).
- 구간 양 끝은 가중치 w = min((i + 1) / (f + 1), (n − i) / (f + 1)) 로 원래 색과 섞는다(f = `feather`, 0이면 w = 1).

### 6. 렌더링

- 원본, 분신, 잔상은 같은 폰트로 그리고 글자 주변에 글로우를 준다.
- 분신 색: 원본 색의 색조는 그대로 두고 채도에 1.25를 곱하며(최대 1) 명도에 0.82를 곱한다. 그라데이션 글자는 분신이 생기는 순간의 색에 같은 식을 쓴다.
- 분신은 대사 영역 밖으로 나가도 잘라내지 않는다.
- 대사가 닫히면 분신 생성을 멈추고, 남은 분신은 대사와 함께 페이드아웃한 뒤 지운다. 화면 밖에 있을 때는 업데이트를 멈춘다.
- 프레임 간격(dt)은 0.05초를 넘지 않게 자른다.

## 6. 미결정·확인 필요 (플머)

이 절과 본문의 "(확인 필요)" 외에는 모두 결정된 사항이다.

| 항목 | 현재 가정 또는 제안 | 확인할 점 |
| --- | --- | --- |
| 없는 프리셋 이름 | 연출 없이 글자만 표시 | 기존 태그 처리 방식 |
| 닫지 않은 태그 | 문장 끝에서 자동으로 닫고 경고 로그 | 기존 태그 처리 방식 |
| 동시 분신 수와 성능 | 대사 하나당 분신 16개, 분신당 잔상 최대 4개. 효과 대사는 한 화면에 여러 개 뜰 수 있다 | 동시에 뜨는 대사 수, 화면 전체의 분신 수 상한, 타겟 기기에서의 허용치 |
| 글자 분할 기준 | 사용자가 보는 한 글자 단위(이모지, 결합 문자 포함) | 사용 엔진과 폰트가 같은 기준을 지원하는지 |
| 그리는 순서 | 분신은 원본 위에 그린다(시안 기준) | 분신이 대사 영역 밖으로 나가므로, 다른 UI보다 위인지 아래인지 |
| 다른 이동 효과 글자의 접촉 반응 | 정하지 않음 | 같은 대사의 `wave` 등이 걸린 글자에 분신이 닿으면, 밀림을 더할지 무시할지 |

## 부록. 시안 사용법 (`index.html`)

- 브라우저로 바로 열린다. 드롭, 상승, 그라데이션 세 칸으로 나뉘어 있다.
- 문구 칸에서 태그를 직접 고쳐 볼 수 있다. 프리셋 버튼을 누르면 문구 안의 태그 이름이 바뀐다.
- 슬라이더로 값을 조절하고 '현재 값 보기·복사'로 값을 복사해 플머에게 전달한다. 슬라이더 범위는 시안 화면에 표시된다.
- 시안의 글자 크기는 화면 폭에 따라 약 22~44px이고, 프리셋 값에 글자 크기 ÷ 40을 곱해 쓴다.
- 드롭·상승 칸의 기본 글자색은 원령 흰색 `#eaf2ff` 이고 분신은 `#92bcff` 로 계산된다. 글자색 버튼으로 다른 색을 볼 수 있다. 그라데이션 칸의 원래 색은 `#d9e0ec` 다.
- 시안에 없는 것: 대사 열림·닫힘과 페이드, 드롭 안의 그라데이션, 여러 대사 동시 표시, 다른 UI와의 겹침.
- 브라우저의 모션 감소 설정이 켜져 있으면 일시정지 상태로 시작한다. 시안에만 있는 동작이다.
