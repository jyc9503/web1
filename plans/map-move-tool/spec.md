## 개요

「스토리 맵 핀 이동 연출」(`plans/story-map-pin-move/`)의 데이터를 만드는 편집 툴이다. 연출 규칙(R-xx)은 그 기획서를 따르고, 이 문서는 **툴에서 어떻게 만드는지**만 다룬다.

- **사용자**: 스토리 연출을 만드는 기획자
- **목표**: 연출 하나를 5분 안에 만든다. 점 몇 개를 찍으면 곡선이 나오고, 앞 연출에서 이어갈 때는 버튼 하나로 시작 상태가 채워진다. `검증필요`
- **원칙**: 툴에서 보는 미리보기와 게임 화면이 같아야 한다. 결과는 연출 기획서 「테이블 설계」의 테이블로 저장한다.
- **단위**: 툴 화면의 좌표·길이는 배경 px, 시간은 ms, 속도는 px/초로 표시한다(연출 R-05, R-37, R-41).
- 동작 프로토타입(`plans/story-map-pin-move/proto/`)이 이 문서의 주요 기능을 구현해 두었다.

## 편집 조작 (실수 방지)

편집 화면에서 "고르려고 눌렀는데 점이 찍히는" 실수를 막는 규칙이다. **한 번 누르기는 선택, 더블클릭은 생성**으로 나눈다. 도구를 바꿀 필요가 없다.

| ID | 요구 | 상태 |
|---|---|---|
| E-01 | **생성은 더블클릭**: 점과 장소 마크는 더블클릭(폰은 더블탭, 같은 자리 10px 안에서 350ms 안)으로만 생긴다. 한 번 누르기는 선택만 한다. | {확정} |
| E-02 | **누르기 우선순위**: 선택한 점의 핸들 → 선택한 핀의 점 → 핀 본체 → 다른 핀의 점 → (더블클릭일 때) 점 추가 → 경로 선 → 빈 곳. 다른 핀이나 그 핀의 점을 누르면 그 핀을 선택할 뿐이다. | {검증필요} |
| E-03 | **끌기 문턱**: 6px 이상 움직여야 끌기로 본다. 그보다 작게 움직인 누르기는 선택만 하고, 실행 취소 기록에도 남지 않는다. | {검증필요} |
| E-05 | **빈 곳과 경로 선**: 한 번 누르면 빈 곳은 선택 해제, 경로 선은 그 핀 선택. 더블클릭하면 빈 곳은 선택한 핀의 끝에 점 추가, 선택한 핀의 경로 선 위는 그 자리에 끼워 넣기. | {검증필요} |
| E-06 | **새 핀·이어가기 안내**: 핀을 새로 추가하거나 이어가기 연출을 만들면 "빈 곳을 더블클릭해 점을 찍으세요"를 안내한다. `Esc`는 선택을 푼다. | {검증필요} |
| E-07 | **재생 중 입력**: 편집 보기에서 재생 중에 캔버스를 누르면 일시정지만 하고 편집하지 않는다. | {검증필요} |
| E-08 | **되돌리기 안내**: 점 추가·끼워 넣기·삭제 직후 "Ctrl+Z 되돌리기" 안내를 띄운다. | {검증필요} |
| E-10 | **누른 대상에 따라 편집 대상 전환**: 핀·경로 편집 중 장소 마크(점이나 이름 글자)를 한 번 누르면 그 장소를 선택하고 장소 편집으로 바꾼다. 장소 위 더블클릭(장소에 붙은 점 추가)과 구분하려고 더블클릭 판정 시간(350ms)이 지난 뒤 바꾼다. 장소 편집 중 핀이나 점을 누르면 그 핀을 선택하고 핀·경로 편집으로 바꾼다. | {확정} |
| E-11 | **겹칠 때 우선순위**: 핀·경로 편집에서는 핀과 점이 장소보다 먼저 잡힌다. 장소 편집에서는 장소 이름 글자 → 핀 → 점 → 장소 점 순서다. 핀이 장소 위에 서 있어도 핀을 누르면 핀이, 이름 글자를 누르면 장소가 잡힌다. | {검증필요} |

## 경로 그리기

경로는 **점(웨이포인트)을 찍어서** 만든다. 직선·곡선은 그리는 방법이 아니라 경로의 속성이다. 같은 점으로 직선과 곡선을 오가며 비교할 수 있다.

### 그리기 방식

| ID | 방식 | 동작 | 상태 |
|---|---|---|---|
| P-01 | 점 찍기 | 빈 곳을 더블클릭할 때마다 선택한 핀의 경로 끝에 점을 추가한다(E-01). | {확정} |
| P-02 | 자유 그리기 | 이번 버전에서 제외한다. 프로그램실 회의에서 필요 여부를 확인한다. | {미정} |

### 경로 형태

| ID | 형태 | 설명 | 상태 |
|---|---|---|---|
| P-03 | 곡선 (기본) | 점만 찍으면 모든 점을 지나는 부드러운 곡선(Catmull-Rom)이 자동으로 나온다. 모양을 더 잡고 싶은 점에서만 베지어 핸들을 꺼낸다(P-17). | {확정} |
| P-04 | 직선 | 점과 점을 직선으로 잇는다. 길·복도처럼 꺾이는 이동에 쓴다. | {확정} |
| P-05 | 구간별 형태 | 한 경로 안에서 구간마다 직선/곡선을 다르게 지정할지. 점별 핸들(P-17)로 대부분 해결되므로 이번 버전은 넣지 않는다. | {확정} |

> **곡선 방식: 자동 곡선 + 필요한 점만 베지어 핸들**
>
> 모든 점에 베지어 핸들을 두면 모양은 정확하지만 점마다 손이 간다. 자동 곡선(Catmull-Rom)은 점만 찍으면 되지만 모양을 세밀하게 잡기 어렵다. 그래서 기본은 자동 곡선으로 빠르게 만들고, 모양이 마음에 들지 않는 점에서만 핸들을 꺼내 다듬는다. 자동 곡선은 내부적으로 핸들을 자동 계산한 베지어와 같으므로, 핸들을 꺼내는 순간 모양이 바뀌지 않고 그 자리에서 조절이 시작된다.

### 점 편집

| ID | 동작 | 방법 | 상태 |
|---|---|---|---|
| P-06 | 점 삽입 | 선택한 핀의 경로 선 위를 더블클릭하면 그 위치에 점을 끼워 넣는다. | {확정} |
| P-07 | 점 이동 / 삭제 | 선택 도구에서 점을 끌어서 옮긴다(E-03 문턱). 점을 선택하고 「선택한 점 삭제」 또는 `Delete`로 지운다. 폰은 길게 누르면 삭제 메뉴가 나온다. | {확정} |
| P-08 | 자유 그리기 단순화 | 자유 그리기(P-02)를 넣을 때만 필요하다. 넣는다면 Douglas-Peucker 방식, 허용 오차 `MAP_TOOL_SIMPLIFY_PX`(배경 16px). | {미정} |
| P-09 | 장소 마크 스냅 | 점을 장소 마크 근처(`MAP_TOOL_SNAP_PX`, 배경 40px 이내)에 놓으면 마크에 붙는다. 붙은 점은 좌표 대신 장소 ID로 저장되어, 장소를 옮기면 경로도 따라간다(연출 R-40). 붙은 점은 다이아몬드 모양으로 표시한다. 켜고 끌 수 있다(기본 켬). | {확정} |
| P-10 | 시작점 고정 | `FromPrev` 핀의 시작점은 앞 연출에서 온다. 저장하지 않고 자물쇠로 표시하며 옮기거나 지울 수 없다. | {확정} |
| P-11 | 실행 취소 / 다시 실행 | 최소 50단계. 점 추가, 이동, 삭제, 속성 변경, 이어가기 가져오기를 모두 포함한다. | {확정} |
| P-12 | 경로 복사 | 선택한 핀의 경로를 다른 핀에 붙여 넣는다. 함께 이동하는 무리를 만들 때 쓴다. 붙여 넣은 경로는 조금 옆으로 비켜 놓는다. 범위는 프로그램실과 논의해 확정한다. | {검증필요} |
| P-13 | 경로 뒤집기 | 경로의 시작과 끝을 바꾼다. 왕복 이동을 만들 때 쓴다. 범위는 프로그램실과 논의해 확정한다. | {검증필요} |
| P-17 | 베지어 핸들 | 점을 선택하고 「핸들 꺼내기」를 누르면 지금 곡선 모양 그대로 양쪽 핸들이 나온다. 핸들을 끌면 반대쪽도 대칭으로 움직이고, `Alt`를 누른 채 끌면 한쪽만 움직인다. 「자동으로 되돌리기」로 핸들을 지운다. 저장 열: `InX`, `InY`, `OutX`, `OutY`(점 기준 상대 px). | {확정} |

### 속도

이동 시간은 기본적으로 속도 프리셋과 경로 길이로 자동 계산된다(연출 R-08). 경로를 고쳐도 속도는 그대로다. 특별한 장면만 시간을 직접 고정한다.

| ID | 요구 | 상태 |
|---|---|---|
| P-14 | 속성 패널에 경로 길이(px), 속도(px/초), 계산된 이동 시간(ms)을 표시한다. | {확정} |
| P-15 | **속도 프리셋**: 핀마다 프리셋(걷기, 달리기, 고속)을 고른다. 기본은 걷기. 「시간 고정」을 켜면 이동 시간(ms)을 직접 입력하고 프리셋은 무시한다. 저장 열: `SpeedPreset`, `DurationMs`. | {확정} |
| P-16 | 속도가 `MAP_SPEED_WARN_PX`(1600px/초)를 넘는 핀은 경고 표시한다(순간이동처럼 보임). 시간 고정 핀에서 주로 생긴다. | {확정} |

| C-02 | 가져오는 것: 배경, 앞 연출 ID, 그리고 앞 연출 핀마다 같은 번호·리소스·이름표·속도 설정의 `FromPrev` 핀. 시작 위치, 앞 궤적, 장소 마크 표시는 **저장하지 않고** 앞 연출에서 계산해 보여준다. | {확정} |
| C-03 | 저장하는 이어가기 정보는 `PrevSceneID` 하나다(연출 R-27). | {확정} |
| C-04 | 앞 연출을 고치면 뒤 연출의 시작 위치·앞 궤적이 자동으로 바뀐다. 저장할 때 "뒤 연출 N개의 시작 위치가 바뀝니다"를 알리고, 뒤 연출에서 깨지는 핀(앞 연출에서 사라진 핀 번호)을 오류 목록에 띄운다. | {확정} |
| C-05 | 연출 목록에서 이어가기 연결(1 → 2 → 3)을 보여주고, 사이에 대사가 있는 것처럼 연결된 연출을 차례로 미리보기 재생할 수 있다(맵 유지 포함). 범위는 프로그램실과 논의해 확정한다. | {검증필요} |
| C-06 | 앞 연출에서 사라짐(on_end: 사라짐)으로 끝난 핀은 가져오지 않는다. | {확정} |
| C-07 | 별도 툴이라 스토리 순서를 모른다. 그래서 `MapScene`의 `Group`(예: C03_MOVE)과 `Order`로 툴 안에서 목록 순서를 관리한다. 스토리 테이블은 `map_play <SceneID>`로만 참조하고, 게임은 순서 정보 없이 "열린 맵"으로 이어가기를 판단한다. | {확정} |
| C-08 | 다른 연출이 `PrevSceneID`로 참조 중인 연출은 지울 수 없다. 지우려면 뒤 연출의 연결을 먼저 끊는다. | {확정} |

| ID | 요구 | 상태 |

| T-06 | 연출 기획서 「테이블 설계」 형식(MapScene, MapPin, MapWaypoint, MapScenePlace, MapPlace)으로 저장하고 불러온다. 「테이블로 보기」는 현재 연출의 행을 탭 구분 텍스트로 보여주어 엑셀에 그대로 붙여 넣을 수 있다. | {확정} |
| T-07 | 저장 전에 검사한다: 배경 범위 밖 좌표, 경로가 빈 핀, 이름 키가 없는 장소 마크, 다른 배경의 장소를 가리키는 점·장소 보임, 앞 연출에 없는 `FromPrev` 핀, 앞 연출과 다른 배경, 없는 기준 핀, 서로를 기다리는 출발 조건, 끊긴 이어가기 연결, 없는 Actor, 속도 경고(P-16), 권장 길이 초과(`MAP_RECOMMEND_MAX_MS`). 오류는 저장을 막고, 경고는 목록만 보여준다. | {확정} |
| T-08 | 기존 스토리 툴과 분리된 별도 툴로 만든다. 스토리 노드는 연출 맵 ID로 참조한다. | {확정} |

## 회사 확인·회의 안건

- 툴 플랫폼(엔진 에디터 확장 / 웹 툴): 회사에서 판단 (T-08)
- 스토리 데이터에서 연출 맵 ID를 참조하는 방식 (C-07)
- 편의 기능 범위: 경로 복사(P-12), 경로 뒤집기(P-13), 이어서 미리보기(C-05), PC 단축키. 넣기로 했고 범위는 프로그램실과 논의
- 자유 그리기(P-02): 이번 버전 제외, 회의에서 프로그램실 의견 확인
- 속도 프리셋 값은 시작값. 실제 연출을 만들며 튜닝 (P-15)
