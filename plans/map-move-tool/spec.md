## 개요

「스토리 맵 핀 이동 연출」(`plans/story-map-pin-move/`)의 데이터를 만드는 편집 툴이다. 연출 규칙(R-xx), 계산식(F-xx), 데이터 형식은 그 기획서(이하 "연출 기획서")를 따르고, 이 문서는 **툴에서 어떻게 만드는지**만 다룬다.

- **사용자**: 스토리 연출을 만드는 기획자 여러 명. 처음 쓰는 사람도 헷갈리지 않고, 사람마다 만든 연출의 품질이 비슷해야 한다. 같은 배경과 장소를 여러 사람이 나눠 쓰며, 회사에서는 파일 잠금(락)과 기존 협업 규칙(id, 이름)으로 충돌을 막는다.
- **대상 기기**: PC(마우스와 키보드). 프로토타입이 폰 터치로도 조작되는 것은 기획 검토를 폰에서 하기 위한 것이고, 툴 요구가 아니다. 터치 기기 지원이 필요해지면 더블탭과 길게 누르기를 같은 규칙으로 쓴다. `검증필요`
- **목표**: 연출 하나를 5분 안에 만든다. 점 몇 개를 찍으면 곡선이 나오고, 앞 연출에서 이어갈 때는 버튼 하나로 시작 상태가 채워진다. `검증필요`
- **원칙**: 툴에서 보는 미리보기와 게임 화면이 같아야 한다. 같은 계산식(연출 기획서 「부록 C 계산 규칙」)을 쓴다.
- **결과물**: 연출 1건당 JSON 1개와 엑셀 테이블 행(`map_scene`, `map_place`, `map_background`). 형식은 연출 기획서 「부록 A 데이터 설계」에 있다.
- **단위**: 툴 화면의 좌표·길이는 배경 px, 시간은 ms, 속도는 px/초로 표시한다.
- 동작 프로토타입(`plans/story-map-pin-move/proto/`)의 「편집 툴」 탭이 이 문서의 주요 기능을, 「데이터」 탭이 저장 형식을 구현해 두었다.
- 기획자용 조작 안내와 「좋은 연출 기준」은 `plans/map-move-tool/guide.md`에 있다. 기준의 원본은 연출 기획서 「연출 작성 기준」이고, 툴은 그중 기계로 볼 수 있는 것을 경고로 알려준다(CK-13, CK-14, CK-18~CK-20).
- 이 문서는 회사 밖에서 회사 데이터 없이 썼다. 테이블·열·필드 이름은 자리표시다.

## 편집 조작 (실수 방지)

편집 화면에서 "고르려고 눌렀는데 점이 찍히는" 실수를 막는 규칙이다. **한 번 누르기는 선택, 더블클릭은 생성**으로 나눈다. 도구를 바꿀 필요가 없다. 모든 규칙은 프로토타입 「편집 툴」 탭에 구현되어 있다.

| ID | 요구 | 상태 |
|---|---|---|
| E-01 | **생성은 더블클릭**: 점과 장소 마크는 더블클릭(같은 자리 10px 안에서 350ms 안)으로만 생긴다. 한 번 누르기는 선택만 한다. | {확정} |
| E-02 | **누르기 우선순위**: 선택한 점의 핸들 → 선택한 핀의 점 → 핀 본체 → 다른 핀의 점 → (더블클릭일 때) 점 추가 → 경로 선 → 빈 곳. 다른 핀이나 그 핀의 점을 누르면 그 핀을 선택할 뿐이다. | {확정} |
| E-03 | **끌기 문턱**: 6px 이상 움직여야 끌기로 본다. 그보다 작게 움직인 누르기는 선택만 하고, 실행 취소 기록에도 남지 않는다. | {확정} |
| E-05 | **빈 곳과 경로 선**: 한 번 누르면 빈 곳은 선택 해제, 경로 선은 그 핀 선택. 더블클릭하면 빈 곳은 선택한 핀의 끝에 점 추가, 선택한 핀의 경로 선 위는 그 자리에 끼워 넣기. | {확정} |
| E-06 | **조작 안내는 문서로**: 툴 안에서 조작 안내 문구를 띄우지 않는다. 툴을 계속 쓰는 기획자가 대상이라 반복 안내는 방해가 된다. 조작법은 사용 안내 문서(`plans/map-move-tool/guide.md`)로 제공한다. `Esc`는 선택을 푼다. | {확정} |
| E-07 | **재생 중 입력**: 편집 보기에서 재생 중에 캔버스를 누르면 일시정지만 하고 편집하지 않는다. | {확정} |
| E-08 | **되돌리기 안내 없음**: 점 추가·끼워 넣기·삭제 뒤 되돌리기 안내를 띄우지 않는다. 실행 취소 버튼과 `Ctrl+Z`만 둔다. | {확정} |
| E-10 | **누른 대상에 따라 편집 대상 전환**: 핀·경로 편집 중 장소 마크(점이나 이름 글자)를 한 번 누르면 그 장소를 선택하고 장소 편집으로 바꾼다. 장소 위 더블클릭(장소에 붙은 점 추가)과 구분하려고 더블클릭 판정 시간(350ms)이 지난 뒤 바꾼다. 장소 편집 중 핀이나 점을 누르면 그 핀을 선택하고 핀·경로 편집으로 바꾼다. | {확정} |
| E-11 | **겹칠 때 우선순위**: 핀·경로 편집에서는 핀과 점이 장소보다 먼저 잡힌다. 장소 편집에서는 장소 이름 글자 → 핀 → 점 → 장소 점 순서다. 핀이 장소 위에 서 있어도 핀을 누르면 핀이, 이름 글자를 누르면 장소가 잡힌다. | {확정} |

## 경로 그리기

경로는 **점(웨이포인트)을 찍어서** 만든다. 직선·곡선은 그리는 방법이 아니라 경로의 속성이다. 같은 점으로 직선과 곡선을 오가며 비교할 수 있다.

### 그리기 방식

| ID | 방식 | 동작 | 상태 |
|---|---|---|---|
| P-01 | 점 찍기 | 빈 곳을 더블클릭할 때마다 선택한 핀의 경로 끝에 점을 추가한다. | {확정} |
| P-02 | 자유 그리기 | 이번 버전에서 제외한다. 프로그램실 회의에서 필요 여부를 확인한다. | {미정} |

### 경로 형태

| ID | 형태 | 설명 | 상태 |
|---|---|---|---|
| P-03 | 곡선 (기본) | 점만 찍으면 모든 점을 지나는 부드러운 곡선(Catmull-Rom)이 자동으로 나온다. 모양을 더 잡고 싶은 점에서만 베지어 핸들을 꺼낸다. | {확정} |
| P-04 | 직선 | 점과 점을 직선으로 잇는다. 길·복도처럼 꺾이는 이동에 쓴다. | {확정} |
| P-05 | 구간별 형태 | 한 경로 안에서 구간마다 직선/곡선을 다르게 지정할지. 점별 핸들로 대부분 해결되므로 이번 버전은 넣지 않는다. | {확정} |

> **곡선 방식: 자동 곡선 + 필요한 점만 베지어 핸들**
>
> 모든 점에 베지어 핸들을 두면 모양은 정확하지만 점마다 손이 간다. 자동 곡선(Catmull-Rom)은 점만 찍으면 되지만 모양을 세밀하게 잡기 어렵다. 그래서 기본은 자동 곡선으로 빠르게 만들고, 모양이 마음에 들지 않는 점에서만 핸들을 꺼내 다듬는다. 자동 곡선은 내부적으로 핸들을 자동 계산한 베지어와 같으므로(연출 F-02), 핸들을 꺼내는 순간 모양이 바뀌지 않고 그 자리에서 조절이 시작된다.

| P-07 | 점 이동 / 삭제 | 점을 끌어서 옮긴다(E-03 문턱). 점을 선택하고 「선택한 점 삭제」 또는 `Delete`로 지운다. | {확정} |

| P-09 | 장소 마크 스냅 | 점을 장소 마크 근처(40px 이내)에 놓으면 마크에 붙는다. 붙은 점은 좌표 대신 장소 id로 저장되어, 장소를 옮기면 경로도 따라간다. 붙은 점은 다이아몬드 모양으로 표시한다. 켜고 끌 수 있다(기본 켬). | {확정} |
| P-10 | 시작점 고정 | 이어가기 연출에서 앞 연출과 같은 번호의 핀은 시작점이 앞 연출에서 온다. 저장하지 않고 자물쇠로 표시하며 옮기거나 지울 수 없다. | {확정} |
| P-11 | 실행 취소 / 다시 실행 | 최소 50단계. 점 추가, 이동, 삭제, 속성 변경, 이어가기 가져오기를 모두 포함한다. | {확정} |
| P-12 | 경로 복사 | 선택한 핀의 경로를 다른 핀에 붙여 넣는다. 함께 이동하는 무리를 만들 때 쓴다. 붙여 넣은 경로는 조금 옆으로 비켜 놓는다. 범위는 프로그램실과 논의해 확정한다. | {검증필요} |
| P-13 | 경로 뒤집기 | 경로의 시작과 끝을 바꾼다. 왕복 이동을 만들 때 쓴다. 범위는 프로그램실과 논의해 확정한다. | {검증필요} |
| P-17 | 베지어 핸들 | 점을 선택하고 「핸들 꺼내기」를 누르면 지금 곡선 모양 그대로 양쪽 핸들이 나온다. 핸들을 끌면 반대쪽도 대칭으로 움직이고, `Alt`를 누른 채 끌면 한쪽만 움직인다. 「자동으로 되돌리기」로 핸들을 지운다. 저장: `in_x`, `in_y`, `out_x`, `out_y`(점 기준 상대 px). | {확정} |

## 이어가기

| ID | 요구 | 상태 |
|---|---|---|
| D-01 | **읽기**: 회사 데이터에서 Actor 테이블(id, 이름, 아이콘), 문자열 테이블, `map_background`, `map_place`, `map_scene`, `map_speed_preset`, `map_config`와 연출 JSON을 읽는다. Actor, 문자열, 속도 프리셋, 설정은 읽기만 한다. | {검증필요} |
| D-02 | **연출 JSON 쓰기**: 저장하면 연출 JSON 파일을 툴이 직접 쓴다. 기본값인 필드는 생략하고, 필드 순서와 들여쓰기(2칸)를 고정해 버전 관리에서 바뀐 줄만 보이게 한다. | {검증필요} |
| D-03 | **엑셀 행 쓰기**: `map_scene`, `map_place`, `map_background`의 바뀐 행을 반영하는 방식은 둘 중 하나로 정한다. (가) 툴이 엑셀 파일에 직접 쓴다. (나) 툴이 붙여넣기용 탭 구분 행을 내보내고 기획자가 엑셀에 붙여 넣는다. | {미정} |

| D-05 | **id 채번**: 새 연출·장소·배경의 id는 회사 채번 규칙을 따른다. 툴은 이미 있는 id를 막는다. | {확정} |
| D-06 | **배경 등록**: 배경 이미지를 고르면 `width`, `height`를 읽어 채운다. 비율이 16:9가 아니면 경고한다(CK-16). | {검증필요} |
| D-07 | **저장 단위**: 저장은 연출 단위다. 저장하지 않은 변경이 있는 연출은 목록에 표시하고, 닫거나 다른 연출로 넘어갈 때 저장할지 묻는다. 여러 사람이 같은 데이터를 동시에 고치는 일은 회사의 파일 잠금(락)으로 막는다. | {확정} |
| D-08 | **데이터 보기**: 현재 연출의 엑셀 행(탭 구분)과 연출 JSON을 화면에서 보고 복사할 수 있다. | {확정} |

| 묶음, 순서, 메모 | 목록에서 편집 | 엑셀 `map_scene.tool_folder`, `sort_order`, `memo` | - |

## 부록 B. 검사 항목

문구는 예시이고 `{ }` 안은 실제 값으로 바뀐다. 같은 규칙으로 빌드 때 한 번 더 검사한다(연출 기획서 「부록 G 구현 전달사항」).

| ID | 조건 | 종류 | 문구 | 상태 |
|---|---|---|---|---|
| CK-01 | 점이나 장소의 좌표가 배경 범위 밖 | 오류 | 핀 {번호}의 점 {순서}이(가) 배경 밖에 있습니다. | {확정} |
| CK-02 | 시작점이 없는 핀 (앞 연출에서 이어지지 않는데 점이 없음) | 오류 | 핀 {번호}에 시작점이 없습니다. | {확정} |
| CK-03 | 이름이 빈 장소 마크 | 오류 | 이름이 없는 장소가 있습니다. | {확정} |
| CK-04 | 점이나 장소 보임이 다른 배경의 장소를 가리킴 | 오류 | 핀 {번호}의 점 {순서}이(가) 다른 배경의 장소를 가리킵니다. | {확정} |
| CK-05 | 앞 연출에서 사라짐으로 끝난 핀의 번호를 다시 씀 | 오류 | 핀 {번호}은(는) 앞 연출에서 사라졌습니다. | {확정} |
| CK-06 | 이어가기 연출의 배경이 앞 연출과 다름 | 오류 | 배경이 앞 연출과 다릅니다. | {확정} |
| CK-07 | 출발 조건의 기준 핀이 연출에 없음 | 오류 | 핀 {번호}의 기준 핀이 없습니다. | {확정} |
| CK-08 | 출발 조건이 서로를 기다림 | 오류 | 핀 {번호}과(와) 핀 {번호}이(가) 서로를 기다립니다. | {확정} |

| CK-12 | 한 연출에 같은 핀 번호가 둘 | 오류 | 핀 번호 {번호}이(가) 겹칩니다. | {검증필요} |

| CK-14 | 이동 끝 시각이 `MAP_RECOMMEND_MAX_MS`(8000)를 넘음 (연출 G-01) | 경고 | 연출이 권장 길이보다 깁니다({길이}ms). | {확정} |
| CK-15 | 같은 배경에 이름이 같은 장소 마크 (M-05) | 경고 | 장소 이름 "{이름}"이(가) 겹칩니다. | {확정} |

| CK-17 | 쉬는 핀의 이름표가 보이는 장소 마크 글자와 겹침 | 경고 | {장소}의 이름이 이름표에 가려집니다. | {검증필요} |
