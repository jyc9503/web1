# 결정 기록: 맵 이동 연출 편집 툴

## 게임 맥락
- 대상: 카오스 제로 나이트메어. `docs/game-context.md`, `plans/story-map-pin-move/decisions.md` 참고.
- 이 툴은 「스토리 맵 핀 이동 연출」의 데이터를 만든다.

## 확정
- 툴에서는 앞으로 갈 경로와 도착 지점이 보인다. (V-01)
- 툴에서 앞 연출의 끝 상태를 쉽게 가져올 수 있어야 한다. (C-01)
- 경로 그리기 방법(직선, 곡선 등)을 정리한다. 양이 많아 연출 기획서와 분리했다.

- 기존 스토리 툴과 분리된 별도 툴로 만든다. (T-08, 2026-11-08)
- 장소 마크 세트는 기획이 툴에서 관리한다. (M-03, 2026-11-08)

- 편집 모드에서 점·장소 생성은 더블클릭만. 한 번 누르기는 선택. (E-01, 2026-11-11)

- 장소를 누르면 장소 편집으로, 핀·점을 누르면 핀·경로 편집으로 자동 전환. 장소 위 더블클릭은 장소에 붙은 점 추가. (E-10, 2026-11-11)

- 저장 형식은 연출 JSON + 엑셀 행. 툴 대상 기기는 PC로 적되 `검증필요`. (2026-11-15)
- E-02, E-11 누르기 우선순위는 지금 순서, E-03 끌기 문턱 6px, E-05 빈 곳·경로 선 동작, E-07 재생 중 누르면 일시정지만. (2026-11-16)
- E-06 툴 안에서 조작 안내 문구를 띄우지 않는다. 계속 쓰는 툴이라 조작법은 별도 사용 안내 문서(`guide.md`)로 해결한다. (2026-11-16)
- E-08 되돌리기 안내는 띄우지 않는다. (2026-11-16)
- M-07 배경을 해상도가 다른 파일로 바꾸면 물어보고 비율 변환한다. (2026-11-16)
