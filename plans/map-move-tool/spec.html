§1개요

「스토리 맵 핀 이동 연출」(plans/story-map-pin-move/)의 데이터를 만드는 편집 툴이다. 연출 규칙(R-xx), 계산식(F-xx), 데이터 형식은 그 기획서(이하 "연출 기획서")를 따르고, 이 문서는 툴에서 어떻게 만드는지만 다룬다.

  • 사용자: 스토리 연출을 만드는 기획자 여러 명. 같은 배경과 장소를 여러 사람이 나눠 쓰며, 회사에서는 파일 잠금(락)과 기존 협업 규칙(id, 이름)으로 충돌을 막는다.
  • 대상 기기: PC(마우스와 키보드). 프로토타입이 폰 터치로도 조작되는 것은 기획 검토를 폰에서 하기 위한 것이고, 툴 요구가 아니다. 터치 기기 지원이 필요해지면 더블탭과 길게 누르기를 같은 규칙으로 쓴다. 검증필요
  • 원칙: 툴에서 보는 미리보기와 게임 화면이 같아야 한다. 같은 계산식(연출 기획서 「부록 C 계산 규칙」)을 쓴다.
  • 결과물: 연출마다 연출 JSON 1개, 장소 세트마다 장소 JSON 1개, 엑셀 map_scene 행. 배경은 기존 story_resource_list에서 고른다. 형식은 연출 기획서 「부록 A 데이터 설계」에 있다.
  • 단위: 툴 화면의 좌표·길이는 배경 px, 시간은 ms, 속도는 px/초로 표시한다.
  • 동작 프로토타입(plans/story-map-pin-move/proto/)의 「편집 툴」 탭이 이 문서의 주요 기능을, 「데이터」 탭이 저장 형식을 구현해 두었다.
  • 기능 전체를 짧게 보려면 연출의 핵심 기획서(plans/story-map-pin-move/core.md)를 먼저 읽는다. 이 문서는 툴 세부를 담은 참고 자료다.
  • 회사 확인, 프로그램실 회의 안건 같은 남은 일은 「부록 E 검증·미결 목록」에 있다.
  • 이 문서는 회사 밖에서 회사 데이터 없이 썼다. 테이블·열·필드 이름은 자리표시다.

§6핀 설정

ID 요구 상태
K-01 핀 대상은 회사 Actor 테이블에서 검색해 고른다(캐릭터, 함대, 오브젝트 등). 이름과 아이콘을 Actor 테이블에서 가져와 보여준다.
K-02 이름표 글자를 문자열 키로 바꾸거나 끌 수 있다. 비워 두면 Actor 이름을 쓴다.
K-03 핀은 핀 번호로 구분한다. 이어가기 연출 사이에서 같은 번호가 같은 핀이다. 새 핀은 이어가기 연결 전체에서 쓰지 않은 가장 작은 번호를 받는다.
K-04 출발 조건: 시간 또는 다른 핀 도착 후, 여기에 오프셋(ms)을 더한다. 함께 출발시키려면 같은 시간을 준다.
K-05 타임라인 막대: 재생 바 위에 핀별 이동 구간을 막대로 보여준다. 보기 전용이며, 수정은 속성 패널에서 한다.
K-06 등장 시점: 처음부터(기본) 또는 출발할 때. 출발할 때 등장하는 핀은 편집 보기에서 반투명으로 보인다.
K-07 핀 삭제: 다른 핀이 이 핀 도착을 기다렸으면 그 출발 조건을 "시간, 0ms"로 바꾸고 알린다. 이어가기 연출에서 앞 연출 핀을 지우면 "연출이 시작될 때 사라집니다"를 알린다. 둘 다 아니면 알리지 않는다. 검증필요
K-09 고급 옵션 접기: 기본 화면에는 Actor, 속도, 출발 조건, 경로 형태만 둔다. 이름표, 등장 시점, 시간 고정은 「고급」에 접고, 기본값이 아니면 표시한다.

§7경로 그리기

경로는 점(웨이포인트)을 찍어서 만든다. 직선·곡선은 그리는 방법이 아니라 경로의 속성이다. 같은 점으로 직선과 곡선을 오가며 비교할 수 있다.

그리기 방식

ID 방식 동작 상태
P-01 점 찍기 빈 곳을 더블클릭할 때마다 선택한 핀의 경로 끝에 점을 추가한다.
P-02 자유 그리기 이번 버전에서 제외한다. 프로그램실 회의에서 필요 여부를 확인한다. 미정

경로 형태

ID 형태 설명
P-03 곡선 (기본) 점만 찍으면 모든 점을 지나는 부드러운 곡선(Catmull-Rom)이 자동으로 나온다. 모양을 더 잡고 싶은 점에서만 베지어 핸들을 꺼낸다.
P-04 직선 점과 점을 직선으로 잇는다. 길·복도처럼 꺾이는 이동에 쓴다.
P-05 구간별 형태 한 경로 안에서 구간마다 직선/곡선을 다르게 지정할지. 점별 핸들로 대부분 해결되므로 이번 버전은 넣지 않는다.

곡선 방식: 자동 곡선 + 필요한 점만 베지어 핸들

모든 점에 베지어 핸들을 두면 모양은 정확하지만 점마다 손이 간다. 자동 곡선(Catmull-Rom)은 점만 찍으면 되지만 모양을 세밀하게 잡기 어렵다. 그래서 기본은 자동 곡선으로 빠르게 만들고, 모양이 마음에 들지 않는 점에서만 핸들을 꺼내 다듬는다. 자동 곡선은 내부적으로 핸들을 자동 계산한 베지어와 같으므로(연출 F-02), 핸들을 꺼내는 순간 모양이 바뀌지 않고 그 자리에서 조절이 시작된다.

점 편집

ID 동작 방법 상태
P-06 점 삽입 선택한 핀의 경로 선 위를 더블클릭하면 그 위치에 점을 끼워 넣는다.
P-07 점 이동 / 삭제 점을 끌어서 옮긴다(E-03 문턱). 점을 선택하고 「선택한 점 삭제」 또는 Delete로 지운다.
P-08 자유 그리기 단순화 자유 그리기를 넣을 때만 필요하다. 넣는다면 Douglas-Peucker 방식, 허용 오차 16px. 미정
P-09 장소 마크 스냅 점을 장소 마크 근처(40px 이내)에 놓으면 마크에 붙는다. 붙은 점은 좌표 대신 장소 id로 저장되어, 장소를 옮기면 경로도 따라간다. 붙은 점은 다이아몬드 모양으로 표시한다. 켜고 끌 수 있다(기본 켬).
P-10 시작점 고정 이어가기 연출에서 앞 연출과 같은 번호의 핀은 시작점이 앞 연출에서 온다. 저장하지 않고 자물쇠로 표시하며 옮기거나 지울 수 없다.
P-11 실행 취소 / 다시 실행 최소 50단계. 점 추가, 이동, 삭제, 속성 변경, 이어가기 가져오기를 모두 포함한다.
P-12 경로 복사 선택한 핀의 경로를 다른 핀에 붙여 넣는다. 함께 이동하는 무리를 만들 때 쓴다. 붙여 넣은 경로는 조금 옆으로 비켜 놓는다. 범위는 프로그램실과 논의해 확정한다. 검증필요
P-13 경로 뒤집기 경로의 시작과 끝을 바꾼다. 왕복 이동을 만들 때 쓴다. 범위는 프로그램실과 논의해 확정한다. 검증필요
P-17 베지어 핸들 점을 고르고 「핸들 꺼내기」를 누르면 지금 모양 그대로 양쪽 핸들이 나온다. 끌면 반대쪽도 대칭으로, Alt+끌기는 한쪽만 움직인다. 「자동으로 되돌리기」로 지운다.

속도

이동 시간은 기본적으로 속도 프리셋과 경로 길이로 자동 계산된다(연출 R-08, F-05). 경로를 고쳐도 속도는 그대로다. 특별한 장면만 시간을 직접 고정한다.

ID 요구
P-14 속성 패널에 경로 길이(px), 속도(px/초), 계산된 이동 시간(ms), 출발 시각(ms)을 표시한다.
P-15 속도 프리셋: 핀마다 걷기(기본), 달리기, 고속 중에서 고른다. 「시간 고정」을 켜면 이동 시간(ms)을 직접 넣고 프리셋은 무시한다.

PC 단축키(Space, Ctrl+Z, Delete, G 등)는 「부록 C PC 단축키」에 있다. 범위는 프로그램실과 논의해 확정한다.

§8장소 마크 편집

ID 요구 상태
M-01 빈 곳을 더블클릭하면 마크를 추가하고 이름 입력란에 커서를 둔다. 이름은 문자열 키로 저장하고, 툴에는 번역 전 원문을 보여준다.
M-02 마크를 한 번 눌러 고르고 끌어서 옮긴다(E-03 문턱). 이름을 바꾸고 지운다.
M-03 장소 마크는 장소 JSON 단위로 묶이고, 그 장소 JSON을 고른 모든 연출이 함께 쓴다. 같은 배경에 장소 표기를 달리하려면 장소 JSON을 새로 만든다(목록에서 memo로 구분). 장소 속성 패널에 이 장소 JSON을 쓰는 연출 수를 적어 두고, 옮길 때마다 알리지는 않는다.
M-04 연출마다 이름 있는 마크의 보임/숨김을 체크로 고른다. 이어가기 연출은 앞 연출 끝에 보이던 마크를 이어받고 바뀐 것만 저장한다. 숨긴 마크는 편집 보기에서 흐리게 보인다.
M-05 마크 이름은 비워 둘 수 있다. 이름 없는 장소는 게임에 안 보이는 기준점이고(연출 R-58), 편집 보기에서만 속이 빈 점으로 보인다. 글자 수 제한은 두지 않는다.
M-06 장소 속성 패널에 위치 입력칸 X, Y(배경 px)를 둔다. 숫자를 고치면 바로 움직이고, 끌면 숫자도 바뀐다. 범위는 배경(2048×1152) 안이다.
M-08 마크를 지우면 그 장소에 붙어 있던 점은 그 자리의 좌표 점으로 바뀌고, 모든 연출의 보임/숨김 목록에서 빠진다. 다른 연출이 이 장소를 쓰면 그 연출 수를 보여주고 확인을 받는다. 아무도 안 쓰면 바로 지운다. 검증필요

§9이어가기

ID 요구 상태
C-01 「앞 연출에서 이어가기」 버튼. 같은 묶음에서 바로 앞 순번의 연출을 기본으로 추천하고, 목록에서 다른 연출도 고를 수 있다.
C-02 가져오는 것: 배경, 앞 연출 id, 앞 연출 핀마다 같은 번호·Actor·이름표·속도의 핀. 이 핀들은 앞 연출 끝 위치에서 자동으로 출발한다. 시작 위치·앞 궤적·장소 표시는 저장하지 않고 계산해 보여준다.
C-03 저장하는 이어가기 정보는 map_scene.link_prev_map_scene_id 하나다.
C-04 앞 연출을 고치면 뒤 연출의 시작 위치·앞 궤적이 자동으로 바뀐다. 따로 알리지 않는다. 앞 연출에서 핀을 지우면 뒤 연출의 같은 번호 핀은 새 핀이 되어 자기 첫 점에서 출발한다(연출 R-23). 첫 점이 없으면 CK-02가 막는다.
C-05 연출 목록에서 이어가기 연결(1 → 2 → 3)을 보여주고, 사이에 대사가 있는 것처럼 연결된 연출을 차례로 미리보기 재생할 수 있다(맵 유지 포함). 범위는 프로그램실과 논의해 확정한다. 검증필요
C-07 툴은 스토리 순서를 모르므로, 연출 목록 순서는 묶음 이름과 순번으로 관리한다(예: C03_MOVE의 1, 2). 게임은 순서 정보 없이 "열린 맵"으로 이어가기를 판단한다.
C-08 다른 연출이 앞 연출로 참조 중인 연출은 지울 수 없다. 지우려면 뒤 연출의 연결을 먼저 끊는다.

§15부록 D. 편집 조작 세부

편집 화면에서 "고르려고 눌렀는데 점이 찍히는" 실수를 막는 규칙이다. 한 번 누르기는 선택, 더블클릭은 생성으로 나눈다. 도구를 바꿀 필요가 없다. 모든 규칙은 프로토타입 「편집 툴」 탭에 구현되어 있다.

ID 요구
E-01 생성은 더블클릭: 점과 장소 마크는 더블클릭(같은 자리 10px 안에서 350ms 안)으로만 생긴다. 한 번 누르기는 선택만 한다.
E-02 누르기 우선순위: 선택한 점의 핸들 → 선택한 핀의 점 → 핀 본체 → 다른 핀의 점 → (더블클릭일 때) 점 추가 → 경로 선 → 빈 곳. 다른 핀이나 그 핀의 점을 누르면 그 핀을 선택할 뿐이다.
E-03 끌기 문턱: 6px 이상 움직여야 끌기로 본다. 그보다 작게 움직인 누르기는 선택만 하고, 실행 취소 기록에도 남지 않는다.
E-05 빈 곳과 경로 선: 한 번 누르면 빈 곳은 선택 해제, 경로 선은 그 핀 선택. 더블클릭하면 빈 곳은 선택한 핀의 끝에 점 추가, 선택한 핀의 경로 선 위는 그 자리에 끼워 넣기.
E-07 재생 중 입력: 편집 보기에서 재생 중에 캔버스를 누르면 일시정지만 하고 편집하지 않는다.
E-10 누른 대상으로 편집 전환: 핀·경로 편집 중 장소를 한 번 누르면 장소 편집으로, 장소 편집 중 핀이나 점을 누르면 핀·경로 편집으로 바뀐다. 장소 위 더블클릭(점 추가)과 구분하려고 350ms 뒤에 바꾼다.
E-11 겹칠 때 우선순위: 핀·경로 편집에서는 핀·점이 장소보다 먼저 잡힌다. 장소 편집에서는 장소 이름 → 핀 → 점 → 장소 점 순서다.
