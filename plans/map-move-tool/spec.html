맵 이동 연출 편집 툴

§1개요

「스토리 맵 핀 이동 연출」(plans/story-map-pin-move/)의 데이터를 만드는 편집 툴이다. 연출 규칙(R-xx), 계산식(F-xx), 데이터 형식은 그 기획서(이하 "연출 기획서")를 따르고, 이 문서는 툴에서 어떻게 만드는지만 다룬다.

  • 사용자: 스토리 연출을 만드는 기획자
  • 대상 기기: PC(마우스와 키보드). 프로토타입이 폰 터치로도 조작되는 것은 기획 검토를 폰에서 하기 위한 것이고, 툴 요구가 아니다. 터치 기기 지원이 필요해지면 더블탭과 길게 누르기를 같은 규칙으로 쓴다. 검증필요
  • 목표: 연출 하나를 5분 안에 만든다. 점 몇 개를 찍으면 곡선이 나오고, 앞 연출에서 이어갈 때는 버튼 하나로 시작 상태가 채워진다. 검증필요
  • 원칙: 툴에서 보는 미리보기와 게임 화면이 같아야 한다. 같은 계산식(연출 기획서 「계산 규칙」)을 쓴다.
  • 결과물: 연출 1건당 JSON 1개와 엑셀 테이블 행(map_scene, map_place, map_background). 형식은 연출 기획서 「데이터 설계」에 있다.
  • 단위: 툴 화면의 좌표·길이는 배경 px, 시간은 ms, 속도는 px/초로 표시한다(연출 R-05, R-37, R-41).
  • 동작 프로토타입(plans/story-map-pin-move/proto/)의 「편집 툴」 탭이 이 문서의 주요 기능을, 「데이터」 탭이 저장 형식을 구현해 두었다.
  • 기획자용 조작 안내는 plans/map-move-tool/guide.md에 있다(E-06).
  • 이 문서는 회사 밖에서 회사 데이터 없이 썼다. 테이블·열·필드 이름은 자리표시다.

§4편집 조작 (실수 방지)

편집 화면에서 "고르려고 눌렀는데 점이 찍히는" 실수를 막는 규칙이다. 한 번 누르기는 선택, 더블클릭은 생성으로 나눈다. 도구를 바꿀 필요가 없다. 모든 규칙은 프로토타입 「편집 툴」 탭에 구현되어 있다.

ID 요구 상태
E-01 생성은 더블클릭: 점과 장소 마크는 더블클릭(같은 자리 10px 안에서 350ms 안)으로만 생긴다. 한 번 누르기는 선택만 한다. 확정
E-02 누르기 우선순위: 선택한 점의 핸들 → 선택한 핀의 점 → 핀 본체 → 다른 핀의 점 → (더블클릭일 때) 점 추가 → 경로 선 → 빈 곳. 다른 핀이나 그 핀의 점을 누르면 그 핀을 선택할 뿐이다. 확정
E-03 끌기 문턱: 6px 이상 움직여야 끌기로 본다. 그보다 작게 움직인 누르기는 선택만 하고, 실행 취소 기록에도 남지 않는다. 확정
E-05 빈 곳과 경로 선: 한 번 누르면 빈 곳은 선택 해제, 경로 선은 그 핀 선택. 더블클릭하면 빈 곳은 선택한 핀의 끝에 점 추가, 선택한 핀의 경로 선 위는 그 자리에 끼워 넣기. 확정
E-06 조작 안내는 문서로: 툴 안에서 조작 안내 문구를 띄우지 않는다. 툴을 계속 쓰는 기획자가 대상이라 반복 안내는 방해가 된다. 조작법은 사용 안내 문서(plans/map-move-tool/guide.md)로 제공한다. Esc는 선택을 푼다. 확정
E-07 재생 중 입력: 편집 보기에서 재생 중에 캔버스를 누르면 일시정지만 하고 편집하지 않는다. 확정
E-08 되돌리기 안내 없음: 점 추가·끼워 넣기·삭제 뒤 되돌리기 안내를 띄우지 않는다. 실행 취소 버튼과 Ctrl+Z만 둔다(P-11). 확정
E-10 누른 대상에 따라 편집 대상 전환: 핀·경로 편집 중 장소 마크(점이나 이름 글자)를 한 번 누르면 그 장소를 선택하고 장소 편집으로 바꾼다. 장소 위 더블클릭(장소에 붙은 점 추가)과 구분하려고 더블클릭 판정 시간(350ms)이 지난 뒤 바꾼다. 장소 편집 중 핀이나 점을 누르면 그 핀을 선택하고 핀·경로 편집으로 바꾼다. 확정
E-11 겹칠 때 우선순위: 핀·경로 편집에서는 핀과 점이 장소보다 먼저 잡힌다. 장소 편집에서는 장소 이름 글자 → 핀 → 점 → 장소 점 순서다. 핀이 장소 위에 서 있어도 핀을 누르면 핀이, 이름 글자를 누르면 장소가 잡힌다. 확정

§5연출 관리

ID 요구 상태
S-01 새 연출: 배경을 고르면 빈 연출을 만든다. id는 D-05 규칙으로 채우고 사용자가 고칠 수 있다. 묶음(tool_folder)은 지금 보고 있는 묶음을 따른다. 검증필요
S-02 연출 복제: 선택한 연출을 새 id로 복사한다. 이어가기 연결(link_prev_map_scene_id)도 그대로 복사한다. 검증필요
S-03 연출 삭제: 확인을 받고 지운다. 다른 연출이 앞 연출로 참조 중이면 지울 수 없다(C-08). 스토리 테이블이 이 연출을 가리키는지는 툴이 알 수 없으므로 "스토리 테이블에서 쓰는지 확인하세요"를 함께 안내한다. 검증필요
S-04 목록 순서와 묶음: 연출을 끌어서 순서를 바꾸면 sort_order를 다시 매긴다. 묶음 이름을 바꾸거나 다른 묶음으로 옮길 수 있다. 검증필요
S-05 메모: 연출마다 한 줄 메모(memo)를 적는다. 목록에 함께 보인다. 검증필요
S-06 배경 등록: 배경 이미지를 고르면 원본 해상도를 읽어 map_background 행을 만든다(D-06). 검증필요

§6핀 설정

ID 요구 상태
K-01 핀 대상은 회사 Actor 테이블에서 검색해 고른다(캐릭터, 함대, 오브젝트 등). 이름과 아이콘은 Actor 테이블에서 가져와 보여준다. 저장: actor_id. 확정
K-02 이름표 글자를 문자열 키로 바꾸거나 끌 수 있다. 비워 두면 Actor 이름을 쓴다. 저장: label_key, show_label. 확정
K-03 핀은 핀 번호로 구분한다. 이어가기 연출 사이에서 같은 번호가 같은 핀이다. 새 핀은 이어가기 연결 전체에서 쓰지 않은 가장 작은 번호를 받는다. 확정
K-04 출발 조건: 시간 / 다른 핀 출발 후 / 다른 핀 도착 후 + 오프셋(ms). 기준 핀은 같은 연출의 핀 목록에서 고른다. 저장: start_type, start_pin_no, start_offset_ms. 확정
K-05 타임라인 막대: 재생 바 위에 핀별 이동 구간을 막대로 보여준다. 보기 전용이며, 수정은 속성 패널에서 한다. 확정
K-06 등장 시점: 처음부터(기본) / 출발할 때. 출발할 때 등장하는 핀은 편집 보기에서 반투명으로 보인다. 저장: show_from. 확정
K-07 핀 삭제: 핀을 지우면 그 핀을 기준으로 삼던 다른 핀의 출발 조건은 "시간, 0ms"로 바뀌고 그 사실을 안내한다. 이어가기 연출에서 앞 연출 핀을 지우면 "이 핀은 연출이 시작될 때 사라집니다"(연출 R-49)를 안내한다. 검증필요
K-08 핀 색: 기본은 핀 번호별 팔레트 색이다. 필요하면 핀마다 색을 직접 고른다. 저장: color. 검증필요

§7경로 그리기

경로는 점(웨이포인트)을 찍어서 만든다. 직선·곡선은 그리는 방법이 아니라 경로의 속성이다. 같은 점으로 직선과 곡선을 오가며 비교할 수 있다.

그리기 방식

ID 방식 동작 상태
P-01 점 찍기 빈 곳을 더블클릭할 때마다 선택한 핀의 경로 끝에 점을 추가한다(E-01). 확정
P-02 자유 그리기 이번 버전에서 제외한다. 프로그램실 회의에서 필요 여부를 확인한다. 미정

경로 형태

ID 형태 설명 상태
P-03 곡선 (기본) 점만 찍으면 모든 점을 지나는 부드러운 곡선(Catmull-Rom)이 자동으로 나온다. 모양을 더 잡고 싶은 점에서만 베지어 핸들을 꺼낸다(P-17). 확정
P-04 직선 점과 점을 직선으로 잇는다. 길·복도처럼 꺾이는 이동에 쓴다. 확정
P-05 구간별 형태 한 경로 안에서 구간마다 직선/곡선을 다르게 지정할지. 점별 핸들(P-17)로 대부분 해결되므로 이번 버전은 넣지 않는다. 확정

곡선 방식: 자동 곡선 + 필요한 점만 베지어 핸들

모든 점에 베지어 핸들을 두면 모양은 정확하지만 점마다 손이 간다. 자동 곡선(Catmull-Rom)은 점만 찍으면 되지만 모양을 세밀하게 잡기 어렵다. 그래서 기본은 자동 곡선으로 빠르게 만들고, 모양이 마음에 들지 않는 점에서만 핸들을 꺼내 다듬는다. 자동 곡선은 내부적으로 핸들을 자동 계산한 베지어와 같으므로(연출 F-02), 핸들을 꺼내는 순간 모양이 바뀌지 않고 그 자리에서 조절이 시작된다.

M-07 배경 이미지를 해상도가 다른 파일로 바꾸면, 그 배경의 장소 마크와 웨이포인트 좌표·핸들을 새 해상도 비율로 함께 바꿀지 묻는다. 확정
M-08 마크를 지우면 그 장소에 붙어 있던 점은 그 자리의 좌표 점으로 바뀌고, 모든 연출의 보임/숨김 목록에서 빠진다. 지우기 전에 영향을 받는 연출 수를 알린다. 검증필요

§13검증·미결 목록

회사에서 확인할 것

  • □툴 플랫폼(엔진 에디터 확장 / 웹 툴): 회사에서 판단 (T-08)
  • □툴이 읽을 회사 데이터의 위치와 형식: Actor, 문자열, 엑셀 테이블을 내보낸 데이터 (D-01)
  • □연출 JSON을 두는 위치와 이름 규칙 (D-02)
  • □문자열 테이블에 새 키를 넣는 절차 (D-04)
  • □새 id의 범위 규칙 (D-05)

프로그램실 회의 안건

  • □엑셀 행 반영 방식: 직접 쓰기 / 붙여넣기용 행 내보내기 (D-03)
  • □편의 기능 범위: 경로 복사(P-12), 경로 뒤집기(P-13), 이어서 미리보기(C-05), PC 단축키. 넣기로 했고 범위는 프로그램실과 논의
  • □자유 그리기(P-02): 이번 버전 제외, 회의에서 프로그램실 의견 확인
  • □확대·이동(V-06)의 조작 방식을 회사의 다른 툴과 맞출지

기획자가 정할 것

  • □v0.12에서 추가한 제안(V-06, V-07, S-01~S-06, K-07, K-08, M-08, D-01~D-07, CK-11, CK-12, CK-16, CK-17)

나중에 다시 볼 것

  • □속도 프리셋 값은 시작값. 실제 연출을 만들며 튜닝 (P-15)
