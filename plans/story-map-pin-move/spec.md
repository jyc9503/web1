## 개요

스토리 대사 사이에 배경 이미지 한 장을 깔고, 그 위에 캐릭터 핀을 올려 정해진 경로로 이동시킨다. 유저는 글을 읽지 않아도 인물들의 위치와 이동 방향, 도착 지점을 파악할 수 있다.

- **목적**: 이동과 위치 정보를 시각으로 전달해 스토리 몰입을 높인다.
- **감정 중심**: 이동 및 위치 정보. 연출의 성공 기준은 "누가 어디서 어디로 갔는지 한 번에 읽힌다"이다.
- **사용 위치**: 스토리 진행 중 노드 하나로 호출한다. `검증필요`
- **기획자 작업**: 편집 툴에서 배경을 고르고, 핀마다 캐릭터와 경로를 지정한다.

### 범위

| 포함 | 제외 (다음 버전) |
|---|---|
| 핀 이동 연출 재생 | 전투·탐험 화면의 맵 |
| 기획자용 편집 툴 요구사항 | 3D 지도, 지형 상호작용 |
| 데이터 구조 | 유저가 직접 핀을 조작하는 기능 |
| 스킵·배속·다시보기 규칙 | 배경 리소스 제작 (배경 담당) |

### 용어

| 용어 | 뜻 |
|---|---|
| 연출 맵 | 이 연출 한 건. 배경 1장과 핀 여러 개로 이뤄진다 |
| 핀 | 캐릭터 1명을 나타내는 표식 |
| 경로 | 핀이 지나가는 웨이포인트(점)의 순서 |
| 웨이포인트 | 경로를 이루는 좌표 하나 |
| 궤적 | 핀이 이미 지나온 경로를 화면에 남긴 선 |

## 처리 흐름

1. 스토리 노드가 연출 맵을 호출한다.
2. 배경을 0.4초 동안 페이드인한다.
3. 모든 핀이 자기 시작 위치(경로 첫 점)에 0.4초 동안 페이드인한다.
4. 핀마다 시작 지연이 지나면 경로를 따라 이동한다. 지난 구간은 궤적선으로 남는다.
5. 핀이 도착하면 지명 라벨을 표시하고, 설정에 따라 유지하거나 사라진다.
6. 모든 핀이 도착하고 1.0초가 지나면 연출이 끝나고 다음 대사로 넘어간다.
7. 재생 중 언제든 스킵하면 최종 위치로 이동한 뒤 종료한다(R-12).

## 데이터 구조

> **프로그래머분께**
>
> - 좌표는 배경 이미지의 왼쪽 위를 (0, 0), 오른쪽 아래를 (1, 1)로 하는 값이다.
> - 이동 위치는 경로를 따라 **거리 기준**으로 계산한다. 경로 전체 길이에서 `이징(t)` 비율만큼 간 지점이 현재 위치다.
> - 곡선은 웨이포인트를 모두 지나는 부드러운 곡선(Catmull-Rom)을 가정한다.
> - 시간과 한도 값은 코드에 넣지 말고 설정 테이블로 분리해 주세요. 검증필요 항목이라 바뀔 수 있다.

## 검증·미결 목록

- 스토리 화면의 실제 UI(대사창 위치, 스킵 버튼, 화면 방향)에 맞는지 확인 (R-15, R-19)
- 핀 한도(8개)와 웨이포인트 한도(12개)가 실제 스토리 연출에 충분한지 (R-06)
- 기존 스토리 연출의 길이 분포와 비교해 3~8초가 적절한지 (권장 총 길이)
- 캐릭터 얼굴 아이콘 리소스가 이미 있는지, 크기가 충분한지 (핀 아이콘)
- 기존 스토리 툴에 이 기능을 붙일 수 있는지 (T-08)
- 배경 담당과 리소스 규격 합의 (R-18)
- 카메라 팬·줌과 핀 겹침 처리 결정 (R-16, R-17)
