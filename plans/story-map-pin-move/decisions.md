# 결정 기록: 스토리 맵 핀 이동 연출

## 게임 맥락
- 회사 정보: Actor 테이블(이름·리소스 경로), 배속은 켬/끔, 시간 ms, 문자열 키. 상세는 `docs/game-context.md`의 「사용자가 알려준 사실」.
- 대상: 카오스 제로 나이트메어(카제나). 상세는 `docs/game-context.md` (웹 검색 요약 기반, 전부 검증필요).
- 이 기획은 **스토리 진행 중에 나오는 연출**이다.
- 스토리 화면의 UI 구성(대사창 위치, 스킵 버튼, 화면 방향)은 아직 모른다. 기존 스토리 UI를 재사용한다고 가정한다 `검증필요`.

## 확정
- 배경 리소스 1장 위에 캐릭터 핀을 올린다. (R-01)
- 핀 1개는 캐릭터 1명이다. (R-02)
- 핀은 기획자가 지정한 경로를 따라 이동한다. (R-03)
- 기획자가 툴에서 핀의 캐릭터와 경로를 지정한다. (R-04, T-01, T-02)

## 확정 (2026-11-08, v0.2 피드백)
- 게임에서는 앞으로 갈 경로와 도착 지점을 보여주지 않는다. 툴에서만 보인다. (R-09)
- 게임에서는 이동한 경로를 점선으로 남긴다. (R-09)
- 배경 이미지 위 각 장소에 이름 마크를 새길 수 있다. (R-20)
- 앞 이동 연출이 끝난 상태에서 이어 시작할 수 있고, 툴에서 쉽게 가져온다. (R-22, T-11)
- 툴의 경로 그리기 방법은 별도 기획서 `plans/map-move-tool/`로 분리한다.

## 확정 (2026-11-08, v0.3 결정)
- 재생 중 화면 탭은 이 연출만 즉시 완료. (R-12)
- 카메라는 이번 버전에서 고정. 기능을 다 만든 뒤 카메라 여부를 다시 검토한다. (R-16)
- 도착한 핀이 겹치면 자동으로 비켜 놓는다. (R-17)
- 스토리 화면은 가로. 배경 전체가 보이게 맞추고 여백 허용. (R-19)
- 앞 연출 궤적은 기본으로 남기고 연출별로 끌 수 있다. (R-25)
- 이동 효과음은 연출당 한 번, 이동 시작에. (R-30)
- 편집 툴은 별도 툴. 장소 마크는 기획이 툴에서 관리. (툴 T-08, M-03)

## 확정 (2026-11-08, v0.4 결정)
- 맵 유지·닫기는 스토리 테이블에서 연출 ID로 켜고 끄는 명령으로 한다. (R-26, R-31)
- 핀은 핀 규격 리소스 전부를 쓸 수 있다. 연관 테이블은 회사에서 확인(또는 확장). (R-02, R-33)
- 장소 마크는 연출마다 등장 시점을 지정할 수 있다. (R-21)
- 카제나 스토리에는 자동 진행, 배속, 다시보기, 대사 로그가 있다. (R-13, R-14, R-35, R-36)

## 확정 (2026-11-08, v0.5 결정)
- 회사는 시간에 ms, 글자에 문자열 테이블 키를 쓴다. (R-37, R-39)
- 좌표는 배경 원본 px 정수. 위치·길이·속도는 배경 기준, 표시 크기는 UI 기준 해상도 px. (R-05, R-41)
- 0ms = 이동 시작. 페이드인은 그 앞 음수 구간. (R-37)
- 이동 시간은 속도 프리셋으로 계산, 필요 시 고정. 출발 조건(시간/출발 후/도착 후). (R-08, R-38)
- 이어가기는 앞 연출 ID만 저장하고 나머지는 계산. (R-27)
- 데이터는 테이블 8개로 설계(한 행 = 한 가지). 설정 키 목록으로 튜닝 값을 모은다.

## 확정 (2026-11-09, 핵심 규칙 확인)
- 검증필요였던 핵심 규칙 16건을 사용자가 확인해 확정.
- 핀은 Actor 테이블 참조(ActorID). 배속은 켬/끔.
- 핀·점 한도 없음.
- 곡선은 자동 곡선 + 필요한 점만 베지어 핸들.
- 장소 마크는 연출마다 보임/숨김만(등장 타이밍 제거).
- 대사 로그는 맵 연출마다 공통 한 줄(전용 아이콘 + "위치 정보 확인"), 누르면 연출 다시 재생.

## 확정 (2026-11-11, 미결 정리)
- 배경은 비율만 16:9 통일, 해상도 자유. 속도는 2048 폭 기준 환산. (R-18)
- 로그 다시 재생은 로그 위 팝업이 기본, 회사 로그 UI에 따라 조정. (R-45)
- 세이브 시 맵 상태 처리는 회사 세이브 구조에 맞춘다(회사 확인).
- 예외 처리, 아트 표현(핀 링·삼각형, 알약 이름표, 핀 색 점선 궤적, 점+외곽선 장소 글자) 확정.
- 속도 프리셋 500/800/1200은 시작값으로 두고 튜닝.
- 툴: 모든 핀의 점 표시, 재생해도 보기 유지, 대사창 가이드는 옵션, 타임라인 막대는 보기 전용. 자유 그리기는 제외하고 회의에서 확인. 편의 기능 범위와 툴 플랫폼은 회사·프로그램실과 결정.
